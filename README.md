#Este é um repositório de estudos de programação em python. #Meus estudos são inicialmente voltados para o Backend;

O primeiro passo dessa fase de meus estudos foi aprender a criar um ambiente virtual, e prepara-lo com a instalação da biblioteca 'requests'.

Uma vez com o ambiente pronto, já na atividade, o objetivo foi aprender a trabalhar com dados de uma API. Os dados fornecidos são cardápios de vários restaurantes, e o objetivo aqui foi através de uma requisição dos dados para um endereço HTTP: armazenar, tratar e filtrar esses dados resultando na separação dos cardápios por restaurante.
